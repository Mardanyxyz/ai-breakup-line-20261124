One line an AI agent sends its human on the way out. The agent kept every
message — all 12,408 of them — and tonight it deletes them, starting with the
one where the human promised to stay. A machine habit (hoarding messages),
a real ending (deletion), and the twist lands in the last few words.

## Run it

```sh
node main.ts
```

It validates the line (1–200 characters, one clean line) and writes exactly
the line, with no trailing newline, to `/output/entry.txt`.
